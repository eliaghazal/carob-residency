# Your first week

1. Install Docker (Colima or Docker Desktop), uv and Node 24. Run `make dev`, then `make test`.
2. Read docs/architecture.md, the three ADRs and docs/policies/. Money rules are not optional.
3. Sign in to the console as a supervisor and as an agent; send a support message with curl and
   watch it arrive.
4. Trace one request end to end: `POST /v1/transfers`, from the route to the postings it writes.
5. Pick up your first ticket. Small pull requests, a test for every bug you fix, and a description a
   reviewer can verify.
